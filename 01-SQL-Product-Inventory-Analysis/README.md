# SQL Product Inventory & Sales Analysis

## Project Overview

This beginner SQL project analyzes product inventory, pricing,
ratings, discounts, and projected revenue.

The goal of this project is to demonstrate how SQL can be used
to answer common business questions related to product inventory
and sales.

## Business Questions

- What is the total inventory value of each product?
- Which affordable products have strong customer ratings?
- Which products have low or moderate stock levels?
- Which categories contain higher-priced products?
- Which highly rated products may require inventory attention?
- Which products could generate strong projected revenue after a discount?

## SQL Skills Demonstrated

- SELECT
- WHERE
- AND / OR
- IN
- BETWEEN
- LIKE
- DISTINCT
- Calculated Columns
- Column Aliases
- Filtering
- Arithmetic Expressions

## Tools Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- GitHub

## What I Learned

This project helped me practice turning business questions into SQL queries,
filtering data using multiple conditions, creating calculated fields,
and analyzing inventory, pricing, and revenue information.
