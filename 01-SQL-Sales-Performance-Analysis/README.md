# SQL Sales Performance Analysis

## Project Overview

This beginner SQL project analyzes sales transaction data to evaluate
revenue, sales representative performance, regional performance,
product categories, payment methods, and high-value transactions.

The goal of this project is to demonstrate how SQL can be used to
turn raw sales data into useful business insights.

## Business Questions

- What are the overall sales performance metrics?
- Which sales representatives generate the most revenue?
- How does sales performance vary by region and product category?
- How are sales representatives performing in the East region?
- Which product categories are the top performers?
- Which transactions are High, Medium, or Low Value?
- How much revenue comes from credit card transactions?
- Which sales representatives generate the most high-value deals?

## SQL Skills Demonstrated
